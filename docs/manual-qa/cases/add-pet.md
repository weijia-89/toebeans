# Add a pet

**Source:** commit `0d86fec2455d` (`docs/beta-smoke-add-medication.md`, section 1).

## Steps

1. Open the Pets tab and tap Add pet, or use the Today empty-state call to action.
2. Fill Name (required). Species, weight, birthdate, and notes are optional.
3. Tap Save.

## Expected result

The pet appears on the Pets list. Tapping it opens pet detail.
