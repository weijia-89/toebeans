# F-Droid tester tutorial

Testers install toebeans from an F-Droid path.
Testers confirm one reminder after that install.
This run does not publish a release.
Wait for the operator to publish before you install.

## Testers

Victoria, the operator, and the operator's spouse install the app.

## Clients

Install Droid-ify, or install the F-Droid client.
Droid-ify is a client.
Droid-ify reads an F-Droid repository.
Droid-ify is not a store you submit to.

## Obtainium first

Obtainium installs an app from a GitHub release.
Use Obtainium first.

1. Install Obtainium.
2. Add the toebeans GitHub release after the operator publishes it.
3. Install toebeans from that release.
4. Open toebeans.

The public git URL is https://github.com/weijia-89/toebeans.

## Small repo second

Use a small F-Droid repo when Obtainium is not the install path.

1. Open Droid-ify.
2. Add the small F-Droid repo the operator sends.
3. Install toebeans from that repo.
4. Open toebeans.

## One reminder

1. Add one pet.
2. Add one medication for that pet.
3. Add one schedule for that medication.
4. Wait until the reminder time.
5. Confirm one reminder on the phone.

## Public listing

IzzyOnDroid is the faster public listing if the main F-Droid queue waits.
Testers do not file that request.
The operator files public listings later.

## Debug cold start

A debug install uses the cold-start block in the manual case.
The case file is docs/manual-qa/cases/fdroid-tester-confirm-one-reminder.md.
A tester with a published release skips that block.
